## ⚡ 如何在 Antigravity 中开启独立小红书运营模块

1. **新建会话**：在 Antigravity 界面左上角点击 `New Chat`；
2. **发送启动指令**：打开 `F:\xhs_operator\START_NEW_CONVERSATION_PROMPT.md`，将其中代码块的内容直接复制发送给 AI；
3. **开始日常操盘**：
   - 扔截图：截取小红书笔记数据发给 AI，AI 自动进行 CES 评分并当场出下一篇调优笔记；
   - 提选题：随手打几个字（例如“今天遇到个印度客户砍价”），AI 秒变 3:4 轮播图文与爆款文案！
